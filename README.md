
نموذج برنامج ادارة مستشفيات مصغر – Mini HIMS  
نظام إدارة معلومات صحية متكامل وخفيف جدًا (بدون باك-إند) للعيادات الصغيرة والمشاريع التعليمية

#### نبذة عن المشروع
«Mini HIMS» هو نظام إدارة معلومات صحية (Health Information Management System) كامل الوظائف، تم تطويره بالكامل باستخدام HTML + CSS + JavaScript فقط (بدون أي سيرفر أو قاعدة بيانات خارجية).

مصمم خصيصًا تعليمياً لمحاكاة انشاء برامج إدارة مستشفيات لـطلاب وخريجي المعلوماتية الصحية

يحتوي على كل الوحدات الأساسية التي تُتوقع في نظام HIMS حقيقي، مع وكل البيانات تُحفظ محليًا في المتصفح باستخدام Local Storage.

Mini HIMS – Lightweight Health Information Management System  
A complete, fully functional HIMS web app built with only HTML, CSS, and JavaScript (no backend, no database) for educational purposes. 

#### Project Overview
Mini HIMS simulation is a professional, production-ready Health Information Management System built entirely with vanilla technologies. Perfect for health informatics students.

All data is saved locally in the browser (Local Storage + IndexedDB) — zero server cost, zero setup.

#### Features & Modules
- Role-based login (Doctor / Nurse / Admin)  
- Smart dashboard with daily stats  
- Full patient management (add, edit, search, archive)  
- Complete patient medical record (history, allergies, medications, past visits)  
- Appointment scheduling with a visual calendar  
- Laboratory results & reports  
- Medication & inventory management  
- Billing and payment tracking  
- Statistical reports (top diseases, revenue, visits)  
- Full Arabic (RTL + English bilingual support with instant switching  
- 100% responsive (mobile, tablet, desktop)  
- Export/Import entire database as JSON  
- Works 100% offline
